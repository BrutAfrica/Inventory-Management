Not connected
Why this is needed. Since everyone opens this app from their own phone or computer, it needs one shared place to keep the data — otherwise each device has its own separate copy. This uses Firebase (Google's free-tier cloud database, no credit card needed for this scale of use):
  1. Go to console.firebase.google.com, sign in with any Google account, click "Add project", give it any name (e.g. "brut-africa"), and finish creation.
  2. In your new project, click the Web icon (</>) to register a web app. Give it any nickname and click "Register app".
  3. Firebase shows a code snippet with a firebaseConfig object. Copy that whole object and paste it below.
  4. In the left sidebar, go to Build → Firestore Database, click "Create database", choose any region, and start in test mode.
Automatic email — how it's wired.
This app sends alerts itself the moment stock leaves a location or gets poured for a tasting, with no click needed. Since it runs in your browser, it sends through EmailJS (free tier is fine — ~200 emails/month). Takes 5 minutes:
  1. Create a free account at emailjs.com, connect your Gmail/Outlook as the "Service".
  2. Create an Email Template with variables: {{wine_name}}, {{event_type}}, {{quantity}}, {{location}}, {{date}}, {{note}}. Set the "To" field to your alert address. One email is sent per movement entry — if you log several wines together, {{wine_name}} lists all of them (one per line) and {{quantity}} is the combined total.
  3. Paste the Service ID, Template ID and Public Key below.
Until these are filled in, alerts are still logged in-app (Movements tab) but marked "not sent."
If EmailJS wants you to pay to add a domain, you don't need to: instead go to EmailJS → Account → Security, turn on "Use Private Key", copy the Private Key from Account → General, and paste it here. This works free and skips the domain check entirely.
